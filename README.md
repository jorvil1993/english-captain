# English with Captain José

App de inglés para un niño de 5 años, hecha a la medida de su perfil.
Funciona sin internet una vez instalada, no tiene anuncios, no pide cuenta
y no manda ningún dato a ningún lado: el progreso se queda en el aparato.

👉 https://jorvil1993.github.io/english-captain/

Acá solo vive la app ya compilada. El código fuente, el contenido y la
investigación en la que se basa el diseño no son públicos.

Las fotos de los futbolistas son de Wikimedia Commons con licencia libre;
el crédito de cada una está dentro de la app, en el panel de papás.
